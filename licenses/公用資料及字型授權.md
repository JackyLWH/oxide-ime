# 公用資料及選用字型

- 倉頡使用 Arthurmcarthur 的 [Cangjie3-Plus](https://github.com/Arthurmcarthur/Cangjie3-Plus)，以同序轉成 Tab 分隔字典，檔頭記載來源修訂。MIT 授權全文見 `Cangjie3-Plus-MIT.txt`。
- 筆劃以原檔提供，使用 Rime Stroke 修訂 `1e8fff9b9494ddec23b0cbc526bcfd8171a6fd48`。碼表存於使用者資料目錄的 `dictionaries/stroke.dict.yaml`，可自行替換。LGPL 3.0 全文見 `Rime-Stroke-LGPL-3.0.txt`，其引用的 GPL 3.0 全文見 `Cifu-GPL-3.0.txt`。 [Rime Stroke 原始碼表](https://raw.githubusercontent.com/rime/rime-stroke/1e8fff9b9494ddec23b0cbc526bcfd8171a6fd48/stroke.dict.yaml)
- 繁轉簡使用 [BYVoid/OpenCC](https://github.com/BYVoid/OpenCC) 的 `TSCharacters.txt` 與 `TSPhrases.txt`，Apache 2.0 授權全文見 `OpenCC-Apache-2.0.txt`。
- 簡轉繁字元表來自[同文堂字典](https://github.com/tongwentang/tongwen-dict)，本專案採用使用者修訂過的 JSON，授權全文見 [Tongwen-dict-MIT.txt](Tongwen-dict-MIT.txt)。詞組表由 OpenCC 的 `STPhrases.txt` 加上同文堂的選詞及異體字規則重建，隨附 OpenCC Apache 2.0 授權。
- 粵拼字典來自 [Rime Cantonese](https://github.com/rime/rime-cantonese)，讀音與分類來自 [CanCLID](https://github.com/CanCLID/rime-cantonese-upstream)。從上游 CSV 建立有序 JSON，並從詞庫補齊可逐字對應的讀音。資料按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode.zh-hant) 授權，出處及貢獻人見 `粵拼資料來源.md` 和 `CanCLID-README.md`。
- 香港用字排名合併 [粵典](https://words.hk/faiman/analysis/charcount/)的公領域字頻及單字表、[香港中文大學](https://humanum.arts.cuhk.edu.hk/Lexis/chifreq/)既有排名快照、Lai 與 Winterstein 的 [Cifu](https://github.com/gwinterstein/Cifu) 及內木一郎的 [香港外字表](https://github.com/ichitenfont/suppchara)。Cifu 採 GPL-3.0，香港外字表採 CC BY 4.0。原始資料版本及授權一併附上。
- TeX Gyre Termes 可選擇從 [CTAN](https://ctan.org/pkg/tex-gyre-termes) 下載，適用 GUST Font License。TW-Kai 可選擇從數位發展部 [CNS11643 全字庫網站](https://data.gov.tw/dataset/5961) 下載，適用該來源所列的政府資料開放授權條款或 OFL 1.1。
