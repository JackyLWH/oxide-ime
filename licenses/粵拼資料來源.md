# 粵拼字音資料

`jyut6ping3.chars.dict.csv.json` 的初始快照由以下兩份資料重建，供同音搜尋及粵拼反查使用。

- CanCLID `char.csv`，修訂 `4cb67a486312e5f0f13cc842433617104d75de87`。按原始出現次序保留字及讀音分類。 [CanCLID 上游詞表](https://github.com/CanCLID/rime-cantonese-upstream/tree/4cb67a486312e5f0f13cc842433617104d75de87) · [讀音資料說明](CanCLID-README.md)
- Rime Cantonese `jyut6ping3.words.dict.yaml`，修訂 `259f0e48bba840c3a2e0d117539e96937f3d89bc`。從詞庫補充可與詞逐字對齊的讀音，並從中文數字補齊 0 至 9 的讀音。補入的讀音標為常用。 [Rime Cantonese](https://github.com/rime/rime-cantonese/tree/259f0e48bba840c3a2e0d117539e96937f3d89bc)

資料採 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode.zh-hant) 授權。輸入法將預設、常用合併為第一級，接著為罕見及棄用。同級按 JSON 次序排列。
