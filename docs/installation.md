# 安裝及使用 Oxide IME v2.0

在 Windows 10 2004 或之後的 x64 Windows 執行 `OxideIme-Setup-v2.0.exe`。安裝程式會登錄 64 位元及 32 位元文字服務。首次安裝可選擇資料目錄、要更新的公用字庫，以及是否下載缺少的 TeX Gyre Termes 或 TW-Kai。略過字型時會使用 Windows 後備字型。

重新開啟要打字的程式，在文字區按 **Win+Space** 選 **Oxide IME**。若清單沒有 Oxide IME，到 Windows **設定 → 時間與語言 → 語言與地區 → 中文（繁體，台灣）→ 語言選項 → 新增鍵盤** 選取。單按 Shift 切至中文，輸入 `a` 再按空白鍵，應上屏「日」。

## 檔案位置

| 路徑 | 內容 |
| --- | --- |
| `C:\Program Files\OxideIME\` | 兩個 TSF DLL、字庫服務、維護程式、第三方授權及 Inno Setup 解除安裝工具。 |
| `%LOCALAPPDATA%\OxideIME\data\` | 公用詞庫、個人詞條、模糊音、剪貼簿簡轉繁規則、更新設定和紀錄，以及日誌輸出位置。 |
| `%LOCALAPPDATA%\OxideIME\docs\安裝及使用.md` | 安裝及使用說明。 |

選擇其他資料目錄時，選取**包含 `dictionaries` 和 `setting` 的上層資料夾**。例如詞庫在 `E:\OxideIME\data\dictionaries`，就選 `E:\OxideIME\data`。也可以選取空資料夾，安裝程式會建立所需目錄。工作列的「開啟資料目錄」顯示實際使用位置。

首次初始化會複製所有範本，並在 `.initialized` 記錄範本的 SHA-256。已有同名檔案會沿用，安裝程式會指出與範本有差異的檔案。重裝、升級或重新登入會沿用已初始化的資料目錄。每次公開字庫更新成功，會更新相應的比對基準。檔案與基準不符或已刪除時，會保留現況並通知你哪組更新已取消。兩份繁轉簡詞表同組更新。

| 資料目錄內的路徑 | 用途 |
| --- | --- |
| `dictionaries/cangjie3.dict.yaml` | 完整倉頡碼表，起始版本來自 Cangjie3-Plus。可用自己的完整碼表替換。 |
| `dictionaries/custom.dict.yaml` | 個人附加詞條。初始範本提供剪貼簿原文、剪貼簿簡轉繁、日期和時間四個指令標記。 |
| `dictionaries/stroke.dict.yaml` | Rime Stroke 筆劃碼表。安裝時提供，可自行替換。 |
| `dictionaries/homophone.fuzzy.yaml` | 同音及粵拼的模糊音規則。 |
| `dictionaries/s2t/custom.json`、`s2t-char.min.json`、`s2t-phrase.min.json` | 剪貼簿簡轉繁規則，自訂詞優先，其次比對標準詞組及單字。 |
| `dictionaries/t2s/TSCharacters.txt`、`TSPhrases.txt` | OpenCC 繁轉簡字表和詞組表。 |
| `dictionaries/jyut6ping3.chars.dict.csv.json` | 同音搜尋和粵拼反查共用字庫。先比分級，同級按 JSON 原有次序。 |
| `dictionaries/common-rank.txt` | 香港常用字排名。用於倉頡預測和速成、筆劃候選，獨立更新。 |
| `dictionaries/build/` | Maintenance 讀取的重建來源。改動或刪除同文堂規則會取消簡轉繁詞組更新。改動或刪除中大快照會取消常用字排名更新。 |
| `setting/startup-mode.txt`、`update-policy.txt`、`update-interval.txt` | 預設中英模式、公開字庫更新選項及週期。 |
| `setting/restart-programs.json`、`setting/last-update.txt` | 設定指定程式重啟或執行更新後建立。 |

字典採 UTF-8。表頭的 `...` 之後，每行依次填詞條、Tab 和小寫編碼。詞條內用 `\n` 表示換行。儲存後，下次輸入會檢查更新。AppContainer 應用程式由同一登入者的本機字庫服務取得候選及選字結果。

## 按鍵與工作列

**Shift** 切換中英，**Ctrl+/** 切換繁簡，反引號暫時進入粵拼。同一登入工作階段的程式共用這些狀態。「繁」原文直出，「簡」把繁體轉為簡體。

未組字時按 **F4**。「輸入方案」可按 **6** 或點擊，依序切換倉頡、速成、筆劃。速成公用字取倉頡碼首尾，例如「你」由 `onf` 變成 `of`。筆劃依橫、豎、撇、捺、折使用 `U I O J K` 或小鍵盤 `7 8 9 4 5`，小鍵盤請開啟 Num Lock。`L` 或小鍵盤 `6` 各代表任意一筆。兩個方案每頁九個候選，以主鍵盤 **1–9** 選字。方向鍵可移到下一頁，點擊候選亦可上屏。長詞顯示前四字及 `...`，上屏保留全文。「預設輸入模式」可設定下次登入用中文或英文。點擊選單外會關閉 F4。

`custom.dict.yaml` 每行用一個 Tab 分開詞條及完整碼。三種輸入方案都可直接輸入同一個碼，例如詞條編碼 `mynote`。筆劃模式同時查符合該按鍵序列的公用筆劃碼和自訂碼。

在工作列右鍵點擊 **中／英**。

- **開啟資料目錄**會開啟目前使用的資料夾。
- **開啟程式目錄**會開啟 Oxide IME 的安裝位置。
- **檢查詞庫更新**會檢查已選擇的公開來源。驗證來源與檔案基準後才套用。被取消的組別會顯示相關檔名。
- **定期更新設定…**可選擇公用資料及檢查週期。預設每七天檢查一次，由登入維護程序執行。已安裝的使用者可勾選「OpenCC／同文堂 簡轉繁詞組表」，更新 `s2t-phrase.min.json`。單字表和自訂規則可自行維護。停用的項目保留現有檔案。
- **重新啟動輸入法**會等候新的字庫服務接手，然後請 TSF 停用輸入服務、嘗試釋放 DLL，再重新啟用輸入法。
- **指定程式重啟設定…**可新增程式，並為每個程式分別設定前景等待時間。初始等待 1.5 秒，0 秒表示偵測到前景後立即處理。程式須在規則生效後開啟。移開焦點會重新計時，每個程序只重啟一次。未儲存過設定時，預設按檔名比對 `League of Legends.exe`，等待 1.5 秒。可以調整時間或移除該項，儲存後以清單為準。
- **詳細日誌**的勾號顯示現時狀態。按一下可開啟或關閉，Windows 可能要求管理員確認。
- **匯出日誌…**可選擇 JSON Lines 檔名及儲存位置，預設開啟使用者資料目錄的 `logs\`。
- **清空 Oxide IME 日誌…**會在確認後清空事件檢視器內的兩個 Oxide IME 通道。
- **關於 Oxide IME**顯示目前載入版本、DLL 架構和資料目錄。

事件檢視器的 **應用程式及服務記錄 → OxideIme** 有 **Operational** 及 **Diagnostic** 兩個通道。排查輸入問題時，可先開啟詳細日誌，重現問題後關閉，再匯出日誌。

同文堂已有指定選詞時會沿用該選擇。上游有兩個候選而沒有指定選詞時，會採用第一個。

## 升級與解除安裝

已安裝的正式版可直接升級。升級會保留現有詞庫和設定，並在首次使用 v2.0 時加入筆劃碼表。舊版的 `cangjie3_custom.dict.yaml` 會保留，請自行將需要的詞條合併至 `custom.dict.yaml`。若應用程式仍載入舊 DLL，Windows 會待重新啟動後清理。從不同目錄註冊過開發版時，先用該版的解除登錄腳本清理。

在 Windows **設定 → 應用程式 → 已安裝的應用程式** 解除安裝 Oxide IME。使用者資料、文件及選裝字型會保留。
