# Oxide IME

以 Rust 和 Windows 原生 Text Services Framework（TSF）製作的個人倉頡三代輸入法，提供 x64 及 x86 文字服務。倉頡碼表、自訂詞條、按鍵與候選顯示參考本機原有 RIME 設定；原 RIME 目錄只作唯讀參考。

目前提供倉頡查字、粵語同音搜尋、粵拼反查、日期時間、剪貼簿候選、Google 配色候選窗、F4 設定選單及自訂長文／多行詞條。候選窗顯示縮略文字，選字時使用原生編輯介面提交完整內容。剪貼簿候選以唯讀方式取得文字。

版本由 [release-version.txt](release-version.txt) 指定。候選窗使用圓角灰框、白底藍色選取框及細頁碼。Windows 依宿主架構載入 x64 或 x86 DLL。日誌操作見 [事件記錄及問題排查](docs/diagnostics.md)。開發、目錄結構及自動驗證方式見 [維護說明](docs/maintenance.md)。粵拼公開資料及授權見 [粵拼資料來源](licenses/粵拼資料來源.md)。

## 安裝與更新

在 x64 Windows 執行 `outputs\OxideIme-Setup-v1.0.exe`。安裝程式會註冊 x64 及 x86 文字服務，附帶上游 Cangjie3-Plus 公用字庫。首次安裝可選擇使用者資料目錄、要更新的公用資料和要下載的缺少字型。v1.0 是正式安裝的起點。後續升級會保留使用者資料並清理被取代的程式檔。 [安裝及使用](docs/installation.md)

### 開發環境註冊

從專案根目錄建置正式產物，已建置時可直接略過這步：

```powershell
pwsh -NoProfile -File .\scripts\build-release.ps1
```

在系統管理員 PowerShell，先切換至專案根目錄，再執行下列對應的指令：

```powershell
# 第一次安裝
pwsh -NoProfile -File .\scripts\register.ps1

# 已安裝，只需更新到 release-version.txt 指定的版本
pwsh -NoProfile -File .\scripts\update-dll.ps1
```

更新後重新開啟要輸入的程式。在文字區按 **Win+Space** 選擇 **Oxide IME**，再單獨按 Shift 由預設英文切換到中文。若選單沒有輸入法，可到繁體中文語言選項新增鍵盤。需要回退且已保留該版 DLL 及字庫服務時，可透過 `.\scripts\update-dll.ps1` 的 `-Version` 指定發行版本。解除安裝前先切回其他輸入法，再以系統管理員執行 `.\scripts\unregister.ps1`。

右鍵點擊工作列上的 **中／英** 可開啟資料或程式目錄、管理字庫更新、設定自動重啟、匯出或清空事件日誌及查看版本。啟用詳細日誌時，選單會顯示勾號。

可在記事本測試 `a`、`2` 選出「曰」，用滑鼠點候選，並確認點編輯區其他地方會取消組字。按反引號輸入 `ngoxx`，選中「我」後應顯示「倉頡模式」。工作管理員搜尋框亦可切中文測試 `a`。組字底線由應用程式決定如何呈現。

## 按鍵

| 按鍵 | 行為 |
| --- | --- |
| 單獨 Shift；或未組字時 Ctrl+Shift+2 | 切換中英。中文組字中切到英文時，先提交原始編碼。 |
| F4 | 未組字時開啟或關閉設定。用數字鍵、方向鍵或空白鍵／Enter 操作，點擊選單外會關閉。「預設輸入模式」設定下次登入時使用中文或英文。 |
| Ctrl+/ | 切換繁簡，短暫顯示「繁／簡」；組字期間亦可使用，並即時更新候選。 |
| \` | 中文模式下，未組字時進入「粵拼模式」。再按一次或按 Esc 即清除未完成的拼音並返回倉頡。切換程式時會保留模式，並清除原程式的未完成拼音。選字、提交原碼或取消而返回倉頡時，均會短暫顯示「倉頡模式」。 |
| Ctrl+\` | 暫時切換本次反查的模糊／精確模式，顯示「模糊拼音」或「精確拼音」。 |
| a–z | 中文模式下輸入倉頡碼；支援現有碼表的編碼補全。 |
| 1、2 或空白鍵 | 選取本頁第一、第二個候選，或以空白鍵選目前候選。 |
| 左／上、右／下 | 移動目前候選。 |
| Page Up／Page Down | 組字期間封鎖；方向鍵移到前後候選時會自動翻頁，每頁兩個候選。 |
| Backspace、Esc | 刪除最後一碼、取消組字。 |
| Enter | 提交原始編碼，保留輸入時的英文字母大小寫。 |

倉頡先按原碼表次序列出完整匹配。編碼補全候選按 `common-rank.txt` 排序，同排名及未列入排名的候選沿用碼表次序。

同音搜尋固定開啟。在倉頡候選上按 `z` 查粵語同音，按 `x` 依次查來源字的完整讀音。選中其他同音字再按 `z` 可繼續查詢。單獨輸入 `xz` 時按原碼查倉頡。退格會還原各層原本選中的候選。同音字使用目前安裝的粵拼 JSON。

粵拼反查會在文字區顯示拼音字母，例如輸入 `ngo`，可以找到「我」。可省略聲調，或依次用 `v`、`x`、`q`、`vv`、`xx`、`qq` 指定第 1 至第 6 聲。`ngoxx` 為第五聲。精確模式只接受標準拼法，指定聲調時亦須吻合。數字鍵 1、2 繼續用於選字。

編輯專案的 `data/dictionaries/homophone.fuzzy.yaml` 可同時調整同音搜尋和粵拼反查。`enabled: false` 停用模糊音。每條 `derive/正則式/替換/` 保留原拼法並產生額外拼法，按清單次序執行，支援擷取群組（例如 `$1`）和前後查找。規則套用到帶聲調的標準粵拼。用單引號包規則可保留反斜線。儲存後，下次查字會自動讀取。格式有誤時沿用上一份有效設定。

同音及反查均讀取 `jyut6ping3.chars.dict.csv.json`。「預設」和「常用」排第一級，其次是「罕見」和「棄用」。同級按 JSON 原有次序排列。香港用字排名可獨立更新。

`zdate` 輸出本機日期 `日/月/年`，`ztime` 輸出本機時間 `時:分:秒`。輸入 `z` 時讀取剪貼簿並列出可用候選，接著輸入 `v` 會沿用同一份快照。`zv` 第一個候選為剪貼簿原文（簡體模式會繁轉簡），第二個候選依私人規則簡轉繁。選字會保留換行和表情符號。符合條件的 Notepad++ 編輯區會批量寫入至少 1,024 個 UTF-8 位元組的剪貼簿及自訂字庫候選，並可一次撤銷。詳見 [剪貼簿長文診斷](docs/diagnostics.md#剪貼簿長文)。

簡轉繁規則位於 `data/dictionaries/s2t/`。依次比對 `custom.json` 的自訂詞、`s2t-phrase.min.json` 的標準詞組和 `s2t-char.min.json` 的單字。詞組優先比對較長的詞。存檔後，下次讀取剪貼簿會重新載入規則。

同一 Windows 登入工作階段內，Shift 的中英狀態及 Ctrl+/ 的繁簡狀態由各應用共用。首次登入預設為英文，可在 F4 更改下次登入的預設。右下角由 Windows 原生輸入指示器顯示「中／英」；Windows 要求模式狀態以圖標提供，因此輸入法用微軟雅黑動態繪製透明背景字樣。按 Shift 時，插入點右上方另有短暫提示。一般候選窗位於文字插入點附近；若應用程式沒有提供文字位置，會嘗試使用系統插入點或該控制項的角落。特殊保護欄位及尚未列出的 RIME 擴充功能不在此原型的保證範圍。

## AppContainer 與私人字典

受 AppContainer 和 LPAC 限制的程式可透過同一登入工作階段的本機字庫服務查詢並選取私人詞條。服務驗證 Windows 的連線身分，先回傳縮略文字，選字時只把完整詞條回傳給提出查詢的程序。字庫儲存後會自動重載，服務斷線時顯示「字庫未連線」。

沙盒能透過查碼取得候選文字。私人字典檔案留在使用者目錄，由字庫服務讀取。剪貼簿轉換是獨立功能，沙盒中的私人轉換規則沿用開發環境已有的授權。安裝程式在使用者資料目錄提供四個指令標記、模糊音及剪貼簿簡轉繁規則。現有規則檔和個人詞條均會保留。

Windows 的沉浸式 XAML 文字欄（例如工作管理員搜尋框）支援已登記的 TSF 介面。登入畫面及安全桌面仍未驗證。

候選文字使用 17 點、字型原有的字寬及間距，以及灰階平滑。西文字型優先使用已安裝的 TeX Gyre Termes Regular，後備為 Times New Roman。中文字型優先使用已安裝的 TW-Kai（全字庫正楷體），再用 SimKai（KaiTi）及 KaiU（標楷體）補足缺字。DLL 不附帶字型檔。文字區的字根及應用程式自行繪製的候選仍由應用程式決定外觀。

「香港字」依原 RIME 規則保留基本多文種平面及 U+1F000–U+1FFFF 的字元；「全字」解除此過濾。「簡」只將原文繁轉簡；「繁」直接輸出原文，不進行簡轉繁。全角及標點依原有設定轉換，部分中文標點會提供候選。

## 自訂詞條

正式安裝請用「開啟資料目錄」開啟 `dictionaries/custom.dict.yaml`。預設位置是 `%LOCALAPPDATA%\OxideIME\data`。從開發腳本註冊時使用專案內的 `data\dictionaries\custom.dict.yaml`。字典表頭以 `...` 結束。每筆另佔一行，依次填完整內容、真正的 **Tab** 和小寫英文字母編碼。內容中的 `\n` 代表上屏時換行。

```text
第一行\n第二行<Tab>example
```

儲存為 UTF-8 後，已開啟的程式會在後續輸入時自動檢查並重新載入字庫。若正在選字，已顯示的候選先按原字庫提交，之後採用新字庫。格式無效或檔案仍在寫入時會沿用上一份有效字庫。開發版使用專案的 `data/`，公開安裝程式取用 `assets/templates/` 的初始範本。

如要沿用舊 `cangjie3_custom.dict.yaml` 的詞條，請自行合併至 `custom.dict.yaml`。

字典內 `__rime_clipboard_raw__`、`__rime_clipboard_s2t__`、`__rime_time__`、`__rime_date__` 是保留的命令標記，請保留其編碼欄位；輸入法會以動態候選取代標記，不會把標記本身上屏。
